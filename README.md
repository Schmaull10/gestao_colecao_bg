# Gestão Coleção BG — V1.4

PWA pessoal para gestão da coleção, compras, vendas, expansões, Wishlist/ranking e estatísticas.

- Interface: GitHub Pages
- Dados: repositório privado `Schmaull10/gestao_colecao_bg_data`
- O token GitHub e o token BGG são guardados apenas no `localStorage` de cada dispositivo.
- O repositório público não contém a coleção do utilizador.
